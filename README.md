A dying phone sends its final text at 1% battery: a last confession that its owner's "five more minutes" was really three hours — 136 characters, in the phone's own voice, after counting all 847 times it happened.

No dependencies, arguments, or network needed: plain `python3` is enough.

## Run it

```bash
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
